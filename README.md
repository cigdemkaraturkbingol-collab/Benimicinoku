# Benim İçin Oku

Görme engelli kullanıcılar için sade ve erişilebilir bir Android sesli kitap uygulaması.

## İlk prototipte
- Büyük, yüksek kontrastlı kontroller
- TalkBack için içerik açıklamaları
- Türkçe konuşma tanıma ile kitap seçme
- “Küçük Prens'i aç”, “Sherlock Holmes'u oynat”, “oynat”, “duraklat”, “hangi kitaplar var?” gibi komutlar
- Android Text-to-Speech ile metni sesli okuma
- API anahtarı gerektirmeyen temel yapı

Şimdilik telif sorunu oluşturmamak için yalnızca kısa demo metinleri bulunur. İleride kamu malı eserler ve kullanıcının kendi EPUB/TXT/PDF dosyaları desteklenebilir.

## Amaç
Uygulamayı mümkün olduğunca ekrana bakmadan kullanılabilir hâle getirmek ve erişilebilirliği projenin merkezinde tutmak.
